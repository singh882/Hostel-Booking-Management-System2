# Hostel Booking Management System

A Java-based Data Structures and Algorithms project developed as part of summer training. The project manages hostel rooms, student bookings, cancellations, waiting lists, booking history, and complaints using core DSA concepts.

## Project Overview

The Hostel Booking Management System is a console-based Java application designed to simplify basic hostel management operations. It demonstrates the practical use of data structures and algorithms through different hostel-related operations.

## Features

- Book a hostel room
- Cancel a booking
- Search for a student
- Display hostel room details
- View hostel statistics
- Maintain booking history
- Add and display complaints
- Maintain a waiting list when rooms are unavailable
- Automatically allocate available rooms to students from the waiting list

## DSA Concepts Used

- **Linked List:** Used for maintaining and traversing hostel room records.
- **Queue:** Used for maintaining students in the waiting list using FIFO order.
- **ArrayList:** Used for storing students associated with rooms.
- **Stack/History Structure:** Used for maintaining booking history and tracking booking-related operations.
- **Searching and Traversal:** Used for finding rooms and students and displaying hostel information.

## How to Run

1. Install Java JDK on your system.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code or any Java-supported IDE.
4. Compile the Java files.
5. Run `Main.java`.
